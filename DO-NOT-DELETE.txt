Deleting or moving this directory removes the "CK3 模组开发" preset and every
ck3mod_* tool from the profile until the bundle is reinstalled with:

    plugin_manager  action: install_bundle  target: %USERPROFILE%\dsh-bundles\ck3moddev

---

This file lives in the repository on purpose: the sync command below uses /MIR,
which deletes any destination file that is not in the source. Keeping the marker
in the source is what stops the sync from deleting it.

编辑代码时改仓库，再同步过来：

    robocopy "D:\DSH workspace\dsh-ck3-mod-dev" "%USERPROFILE%\dsh-bundles\ck3moddev" /MIR /XD .git test node_modules

同步后**必须重启 DSH** 才会生效：Host 进程会缓存已加载的 ESM 模块，插件页关开
与 HMR 重载都只重新装配配置，不会重新读代码。只改 cordis.patch.yml 的配置值，
则不需要重启（但要手动重载一次）。不想重启又想让新代码生效：把 patch 里的 `?v=2`
加一，再把 bundle 关开一次（Node 按完整 URL 缓存 ESM 模块）。

排查「预设加载失败」：先看 %TEMP%\ck3moddev-activation.json（ok / tools / maskedGlobals / 错误栈）。
